# Деплой и окружение

Как [[Архитектура WebStudio|WebStudio]] собирается и деплоится.

## Переменные среды

Только `VITE_*` переменные попадают в бандл. Всё без этого префикса считается серверным и клиенту недоступно.

| Переменная | Обязательна | Назначение |
|---|---|---|
| `VITE_SUPABASE_URL` | ✅ | URL проекта Supabase |
| `VITE_SUPABASE_ANON_KEY` | ✅ | Публичный `anon` ключ (не `service_role`!) |
| `VITE_MYMEMORY_EMAIL` | ❌ | Email для MyMemory API — поднимает лимит 5к→50к слов/день |

Локальная разработка: `.env.local` (в `.gitignore`, **никогда не коммитить**). Шаблон — `.env.example`.

### Валидация при старте
`src/lib/env.ts` — Zod-схема проверяет переменные через `import.meta.env` при запуске приложения. Если `VITE_SUPABASE_URL` или `VITE_SUPABASE_ANON_KEY` пусты — приложение бросает ошибку сразу, не в рантайме.

## Vercel (основной хостинг)

`vercel.json` делает две вещи:

**1. SPA-rewrite** — критично для React Router:
```json
"rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
```
Без этого F5 на `/:lang/services` вернёт 404 (сервер не знает о клиентских маршрутах). Весь роутинг обрабатывает [[Маршрутизация|router.tsx]].

**2. Заголовки безопасности** — дублируют `public/_headers` (см. [[Безопасность RLS и CSP]]). `_headers` работает на Cloudflare/Netlify, `vercel.json` — на Vercel. Оба файла поддерживаются в синхронизации.

## Команды

```bash
npm run dev          # Vite dev-сервер → http://localhost:5173
npm run build        # TypeScript → Vite → dist/
npm run preview      # Локальный просмотр production-сборки
npm run typecheck    # tsc --noEmit (без emit, только проверка типов)
npm run lint         # ESLint
npm run test:run     # Vitest, один прогон (для CI)
```

**Перед каждым коммитом:**
```bash
npm run typecheck && npm run lint && npm run test:run
```
PR без прохождения этой тройки не мержится.

## Суpabase CLI

Миграции применяются через Supabase Dashboard SQL Editor или:
```bash
supabase db push
```
Конфиг в `supabase/config.toml`. Миграции в `supabase/migrations/` — порядок важен (0001 → 0004).
