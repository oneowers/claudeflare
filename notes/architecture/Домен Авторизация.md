# Домен Авторизация

`src/features/auth/` — вход в админ-панель WebStudio.

## Поток входа
1. `LoginPage` (`/:lang/admin/login`) → форма email + password → `useSignIn`.
2. `useSignIn` вызывает `api.ts` → `supabase.auth.signInWithPassword(...)`.
3. Supabase выдаёт JWT-сессию; `persistSession: true` в [[Точка входа и провайдеры|supabase.ts]] — хранится в localStorage.
4. `ProtectedRoute` проверяет наличие сессии через `useSession` (обёртка над `supabase.auth.getSession`).

## Компоненты и хуки
- `useSession` — отдаёт `{ session, loading }`, реагирует на `onAuthStateChange`.
- `useSignIn` — мутация входа, редиректит на `/admin` после успеха.
- `ProtectedRoute` — HOC-wrapper для всей админ-зоны в [[Маршрутизация]].

## Роли
Единственная роль с правами — `admin` в таблице `profiles`. Проверяется на стороне Supabase функцией `is_admin()` (см. [[Безопасность RLS и CSP]]). ProtectedRoute видит только **наличие сессии**, не роль — RLS не даст залогиненному не-админу читать/писать данные.

## Сессия
- `autoRefreshToken: true` — токен обновляется автоматически.
- `detectSessionInUrl: true` — обрабатывает magic link / OAuth callback (если подключать в будущем).
- При разлогине — `supabase.auth.signOut()`.
