# Домен Лиды

`src/features/leads/` — заявки из контактной формы. Особый домен: запись анонимная, чтение только admin.

## Публичная часть
- `ContactPage` → `ContactForm` → `useCreateLead`.
- Посетитель заполняет: имя, email, телефон (опционально), сообщение, выбор услуги (опционально).
- Мутация вставляет строку в `leads` — RLS разрешает `INSERT with check (true)` для всех (см. [[Безопасность RLS и CSP]]).

## Админ-часть (`/:lang/admin/leads`)
- `LeadsPage` → `LeadsTable` — список заявок с фильтром по статусу.
- `LeadDetailPage` → `LeadDetail` + смена статуса.
- `LeadStatusBadge` — цветной бейдж статуса.

## Статусы заявки
`new` → `in_progress` → `closed` | `spam` (constraint в [[Supabase и база данных|БД]]).

## Данные
Таблица `leads`:
- `name`, `email`, `phone?`, `message`.
- `service_id → services(id) ON DELETE SET NULL` — связь с [[Домен Услуги]].
- `status` — текущее состояние обработки.
- `notes` — внутренние заметки администратора.

## Особенности
- `useLeadCounts` — хук для счётчика на дашборде (сколько `new` заявок).
- Нет `is_published` и `sort_order` — не нужны.
- Лиды **не имеют** публичного list-эндпоинта — только insert.
