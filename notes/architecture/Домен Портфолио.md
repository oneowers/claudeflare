# Домен Портфолио

`src/features/portfolio/` — кейсы студии. Аналогичен [[Домен Услуги]] по [[Паттерн feature-slice]].

## Публичная часть
- `PortfolioPage` → список опубликованных кейсов → `usePortfolio({ publishedOnly: true })`.
- `PortfolioDetailPage` → один кейс по `slug`.
- `PortfolioCard` — карточка с превью.

## Админ-часть (`/:lang/admin/portfolio`)
- `PortfolioListPage` → `PortfolioTable`.
- `PortfolioFormPage` — создание и редактирование. Содержит `TagInput` — компонент ввода технологий.

## Данные
Таблица `portfolio` в [[Supabase и база данных]]:
- `slug`, `title`, `client`, `description`, `image_url`.
- `project_url` — ссылка на живой проект.
- `technologies text[]` — массив тегов (PostgreSQL array).
- `is_published`, `sort_order`.
- Локализованные поля через `*_i18n` JSONB (миграция 0004), см. [[Локализация i18n]].

## Отличия от услуг
- Нет `price_from`/`currency`.
- Есть `client`, `project_url`, `technologies[]`.
- `TagInput` вместо `FeaturesInput`.

## Хуки
`usePortfolio`, `useCreatePortfolio`, `useUpdatePortfolio`, `useDeletePortfolio`, `useTogglePortfolioPublished`.
