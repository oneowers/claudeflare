# Домен Услуги

`src/features/services/` — эталонный домен по [[Паттерн feature-slice]].

## Публичная часть
- `ServicesPage` → список опубликованных услуг → `useServices({ publishedOnly: true })`.
- `ServiceDetailPage` → одна услуга по `slug` → `useService(slug)`.
- `ServiceCard` — карточка на публичной странице.

## Админ-часть (`/:lang/admin/services`)
- `ServicesListPage` → `ServicesTable` со всеми услугами (включая неопубликованные).
- `ServiceFormPage` — создание (`/new`) и редактирование (`/:id/edit`). Форма с [[Локализация i18n|LocaleTabs]] для RU/EN/UZ полей.
- `FeaturesInput` — компонент ввода списка фич (многоязычный).

## Данные
Таблица `services` в [[Supabase и база данных]]:
- `slug` — URL-идентификатор (уникальный).
- `price_from` + `currency` (USD/EUR/UZS/RUB).
- `is_published` — тумблер видимости (публичный SELECT только `is_published = true`).
- `sort_order` — ручная сортировка.
- `name_i18n`, `short_description_i18n`, `description_i18n`, `features_i18n` — JSONB переводы.

## Картинки
Бакет `service-images`, поток описан в [[Загрузка изображений]].

## Хуки
`useServices`, `useService`, `useCreateService`, `useUpdateService`, `useDeleteService`, `useToggleServicePublished`. Все в `hooks/`, данные через [[Слой данных React Query]].
