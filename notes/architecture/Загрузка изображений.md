# Загрузка изображений

Supabase Storage для картинок услуг и портфолио.

## Бакеты
- `service-images` — картинки [[Домен Услуги]].
- (аналог для [[Домен Портфолио]])

## Правила загрузки
1. Максимум **5 МБ** — проверяется на клиенте (`<ImageDropzone>`), плюс политика на бакете.
2. Имя файла — `${crypto.randomUUID()}.{ext}` — никогда не использовать пользовательское имя.
3. После upload сразу `getPublicUrl(path)` → сохранить URL в БД.
4. При обновлении записи старая картинка **не удаляется** — это orphan cleanup (отдельный фоновый процесс, не синхронный).

## Компонент
`src/components/shared/ImageDropzone.tsx` — общая обёртка над `react-dropzone`. Используется во всех доменных формах через [[Паттерн feature-slice|forms]].

## Поток в api.ts (на примере `services`)
```ts
async function uploadServiceImage(file: File): Promise<string> {
  const ext = file.name.split('.').pop()?.toLowerCase() ?? 'jpg';
  const path = `${crypto.randomUUID()}.${ext}`;
  await supabase.storage.from(BUCKET).upload(path, file, {
    cacheControl: '31536000', upsert: false
  });
  return supabase.storage.from(BUCKET).getPublicUrl(path).data.publicUrl;
}
```

## Безопасность
Storage-политики контролируют, кто может писать в бакеты — аналогично [[Безопасность RLS и CSP|RLS-политикам]] на таблицах (миграция `0002_storage.sql`). Публичные URL доступны всем для чтения; запись — только `is_admin()`.
