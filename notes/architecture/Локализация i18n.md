# Локализация i18n

Три языка, язык живёт в URL. Задействует [[Маршрутизация]] и [[Supabase и база данных|БД]].

## Языки
`ru` (default), `en`, `uz` — определены в `src/i18n/config.ts`. UI-строки в `src/i18n/locales/{ru,en,uz}.json`.

## Язык в URL
Все маршруты — `/:lang/...`. Компонент `<LanguageBoundary>`:
1. Проверяет `:lang` — если невалидный, редирект на `/:ru/...`.
2. Вызывает `i18n.changeLanguage(lang)` и ставит `document.documentElement.lang`.

`<LanguageRedirect>` (на `/`) определяет язык из `localStorage` → `navigator.language` → `ru`.
`<LegacyPathRedirect>` — обрабатывает пути без языкового префикса.

## Локализованные данные в БД
`services` и `portfolio` хранят переводы в JSONB-колонках `*_i18n`:
```ts
type LocalizedString = Partial<Record<'ru' | 'en' | 'uz', string>>
type LocalizedStringArray = Partial<Record<'ru' | 'en' | 'uz', string[]>>
```
`pickLocale(value, lang)` — выбирает лучший перевод, fallback → `ru` → любой непустой.
`ru` — единственный **обязательный** язык в Zod-схемах (`requiredLocalizedString`).

## Автоперевод (MyMemory API)
`src/features/translation/api.ts` — бесплатный MyMemory API (`api.mymemory.translated.net`), не требует ключа. Лимит: ~5 000 слов/день анонимно, ~50 000/день с email (`VITE_MYMEMORY_EMAIL`). Длинный текст режется на чанки ≤ 480 символов. Разрешён в [[Безопасность RLS и CSP|CSP]] → `connect-src`.

## Компоненты
- `<LanguageSwitcher>` — переключатель языка в хедере.
- `<LocaleTabs>` — вкладки RU/EN/UZ в формах.
- `useCurrentLanguage()`, `useLocalizedPath()`, `<LocalizedLink>` — хуки и компонент для навигации с сохранением языка.
