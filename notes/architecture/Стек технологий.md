# Стек технологий

Из чего собран [[Архитектура WebStudio|WebStudio]].

## Сборка и язык
- **Vite 5** — dev-сервер (`localhost:5173`) и production-сборка в `dist/`.
- **React 18** — только функциональные компоненты.
- **TypeScript strict** — `any` запрещён. Алиас `@/` → `src/`.

## UI
- **Tailwind CSS** + **shadcn/ui** (поверх Radix), иконки **lucide-react**.
- Условные классы — через `cn()` из `@/lib/utils`.
- Toast-уведомления — **sonner** (`<Toaster>` в [[Точка входа и провайдеры]]).

## Данные и формы
- **React Router v6** — см. [[Маршрутизация]].
- **TanStack Query v5** — серверное состояние, см. [[Слой данных React Query]].
- **React Hook Form + Zod** — формы и валидация (единый источник истины в `schemas.ts`).
- **Supabase JS** — auth, БД, storage, см. [[Supabase и база данных]].
- **react-dropzone** — внутри [[Загрузка изображений]].

## Локализация и тесты
- **react-i18next** + кастомный язык-в-URL роутинг, см. [[Локализация i18n]].
- **Vitest + React Testing Library** — тесты рядом с исходником (`*.test.tsx`).

## Структура
Feature-sliced, см. [[Паттерн feature-slice]]. Бизнес-логика — в `src/features/{domain}/`, страницы (`src/pages/`) — только композиция.
