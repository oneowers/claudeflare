# Точка входа и провайдеры

Как стартует приложение [[Архитектура WebStudio|WebStudio]].

## Цепочка запуска
1. `index.html` содержит `<div id="root">`.
2. `src/main.tsx` находит `#root`, импортирует `./i18n` (инициализация [[Локализация i18n]]) и `globals.css`, рендерит `<App/>` в `React.StrictMode`.
3. `src/App.tsx` оборачивает всё в провайдеры:

```
<QueryClientProvider client={queryClient}>   // см. [[Слой данных React Query]]
  <RouterProvider router={router} />          // см. [[Маршрутизация]]
  <Toaster richColors position="top-right" /> // sonner
</QueryClientProvider>
```

## Что это даёт
- Любой компонент имеет доступ к React Query (хуки `useQuery`/`useMutation`).
- Маршрутизация и язык-в-URL работают глобально.
- `toast.error(...)` доступен везде для ошибок мутаций.

Дальше управление уходит в [[Маршрутизация]], которая выбирает layout и страницу.
