# Архитектура WebStudio

Центральная карта (MOC) для понимания сайта **WebStudio** — SPA-студии веб-разработки. Открой граф (Open Graph), чтобы увидеть, как заметки связаны.

> Тип системы: **чистый клиентский SPA** (Vite + React) + **Supabase** как backend. Нет SSR и API-роутов в репозитории.

1. [[Стек технологий]] — из чего собран проект.
2. [[Точка входа и провайдеры]] — как стартует приложение.
3. [[Маршрутизация]] — какие страницы есть и как они защищены.
4. [[Слой данных React Query]] — как данные ходят между UI и Supabase.
5. [[Supabase и база данных]] — где живут данные.

## Поток в двух словах

Публичный посетитель открывает `/:lang/...` → [[Маршрутизация]] рисует [[Точка входа и провайдеры|публичный layout]] → страница вызывает хук из [[Слой данных React Query]] → хук бьёт в `api.ts` домена → Supabase отдаёт только опубликованные строки по [[Безопасность RLS и CSP|RLS]]. Заявка из формы [[Домен Лиды]] пишется анонимно. Админ логинится ([[Домен Авторизация]]) и через те же домены делает CRUD.
