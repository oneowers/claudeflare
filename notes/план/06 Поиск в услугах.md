# 06 — Поиск и фильтрация в услугах

← [[05 Lazy loading маршрутов]] | [[План улучшений]] | следующий: [[07 Фильтр в портфолио]]

## Проблема

`ServicesPage` выводит все услуги сеткой без возможности поиска. При росте количества услуг пользователь вынужден скроллить всё.

## Что сделать

Клиентский поиск по уже загруженным данным — без нового сетевого запроса.

1. Добавить `useState<string>('')` для поискового запроса.
2. Отфильтровать данные перед рендером:
   ```tsx
   const query = search.toLowerCase();
   const filtered = (services.data ?? []).filter(s => {
     const name = pickLocale(s.name, lang)?.toLowerCase() ?? '';
     const desc = pickLocale(s.short_description, lang)?.toLowerCase() ?? '';
     return name.includes(query) || desc.includes(query);
   });
   ```
3. Поле ввода — компонент `<Input>` из shadcn/ui с иконкой `Search` из lucide.
4. При пустом `filtered` — показать `<EmptyState>` из [[Shared компоненты]].
