# 07 — Фильтр по технологиям в портфолио

← [[06 Поиск в услугах]] | [[План улучшений]] | следующий: [[08 Breadcrumbs]]

## Проблема

Поле `technologies[]` уже хранится в каждом кейсе и отображается на карточке, но нет возможности отфильтровать портфолио по стеку. Потенциальный клиент, ищущий «React-проект», вынужден смотреть всё.

## Что сделать

1. Собрать уникальные технологии из загруженных данных:
   ```ts
   const allTags = useMemo(() =>
     [...new Set((portfolio.data ?? []).flatMap(p => p.technologies))].sort(),
     [portfolio.data]
   );
   ```
2. `useState<string[]>([])` для активных фильтров.
3. Рендерить теги как кнопки-пилюли (shadcn `Badge` или кастомный). Активный тег — выделен цветом.
4. Фильтрация:
   ```ts
   const filtered = active.length === 0
     ? portfolio.data
     : portfolio.data?.filter(p =>
         active.every(tag => p.technologies.includes(tag))
       );
   ```
5. При пустом результате — `<EmptyState>`.
