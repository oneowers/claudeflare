# 11 — Блок отзывов и цифры студии на главной

← [[10 Улучшить 404]] | [[План улучшений]] | следующий: [[12 Анимации появления секций]]

## Проблема

`HomePage` сейчас: герой → услуги → портфолио → CTA. Нет социального доказательства. Потенциальный клиент не видит, почему стоит доверять студии.

## Что сделать

### Вариант A — Цифры (проще, данные статические)
Секция между «портфолио» и «CTA»:
```
5 лет   ·   48 проектов   ·   32 клиента   ·   98% довольных
```
Реализация: просто JSX с `hardcoded` данными + анимация счётчика при появлении в viewport (`IntersectionObserver` или `framer-motion`).

### Вариант B — Карточки отзывов
Массив `testimonials` в коде (или отдельная Supabase-таблица):
```ts
{ author: 'Иван К.', company: 'ООО Ромашка', text: '...', avatar?: string }
```
Горизонтальный скролл или сетка 3 колонки.

### Рекомендация
Начать с вариантом A — быстро, без новых таблиц. Вариант B добавить позже как отдельную задачу (новый домен `testimonials` по [[Паттерн feature-slice]]).
