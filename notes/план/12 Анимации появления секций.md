# 12 — Анимации появления секций

← [[11 Блок отзывов на главной]] | [[План улучшений]] | следующий: [[13 Email при новом лиде]]

## Проблема

Контент появляется мгновенно — нет ощущения «живого» сайта. Все секции главной и страниц деталей статичны.

## Что сделать

### Вариант A — Framer Motion (рекомендуется)
```bash
npm install framer-motion
```
Создать `src/components/shared/FadeUp.tsx`:
```tsx
import { motion } from 'framer-motion';

export function FadeUp({ children, delay = 0 }) {
  return (
    <motion.div
      initial={{ opacity: 0, y: 24 }}
      whileInView={{ opacity: 1, y: 0 }}
      viewport={{ once: true, margin: '-80px' }}
      transition={{ duration: 0.5, delay, ease: 'easeOut' }}
    >
      {children}
    </motion.div>
  );
}
```
Обернуть секции `HomePage`, карточки, заголовки страниц деталей.

### Вариант B — CSS + IntersectionObserver (без зависимостей)
Добавить CSS-класс `animate-fade-up` и наблюдать за элементами через `IntersectionObserver`. Подходит, если хочется не добавлять Framer Motion (он ~40 KB).

### Где применить
- Секции `HomePage` — поочерёдно с задержкой.
- Карточки сетки — `staggerChildren` (каждая с `delay += 0.05`).
- Заголовки `ServiceDetailPage`, `PortfolioDetailPage`.
