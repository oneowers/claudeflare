## Проблема

В `ServiceFormPage` и `PortfolioFormPage` нет способа увидеть, как запись выглядит на публичной странице, не выходя из формы. Нужно вручную открыть `/:lang/services/:slug`.

## Что сделать

### Для существующей записи (режим edit)
Добавить кнопку «Открыть на сайте» рядом с заголовком формы:
```tsx
{id && (
  <LocalizedLink
    to={`/services/${form.getValues('slug')}`}
    target="_blank"
    rel="noopener noreferrer"
    className="..."
  >
    <ExternalLink className="h-4 w-4" />
    Посмотреть на сайте
  </LocalizedLink>
)}
```
Иконка `ExternalLink` из lucide. Для портфолио — `/portfolio/:slug`.

### Для новой записи (режим new)
Кнопка заблокирована (disabled) пока не будет сохранено. Tooltip: «Сначала сохраните».

### Опционально: live preview панель
Разделить экран: слева форма, справа `<ServiceDetailPreview>` — рендер данных из `form.watch()` без сохранения. Это сложнее, делать в следующей итерации.
