# 18 — Галерея изображений для портфолио

← [[17 Rich text редактор]] | [[План улучшений]] | следующий: [[19 Конвертация в WebP]]

## Проблема

`portfolio` хранит одно `image_url` — превью. Показать процесс работы, скриншоты экранов или этапы проекта невозможно.

## Что сделать

### 1. Миграция БД
Новый файл `supabase/migrations/0005_portfolio_gallery.sql`:
```sql
alter table public.portfolio add column gallery_urls text[] not null default '{}';
```

### 2. Обновить типы и схему
- `src/features/portfolio/types.ts` — добавить `gallery_urls: string[]`.
- `src/features/portfolio/schemas.ts` — добавить `gallery_urls: z.array(z.string().url()).default([])`.
- `src/features/portfolio/api.ts` — включить в SELECT, UPDATE payload.

### 3. Форма: множественная загрузка
В `PortfolioForm` добавить зону загрузки нескольких файлов (расширить `ImageDropzone` или использовать `useDropzone` напрямую с `multiple: true`). Каждый файл → `uploadPortfolioImage()` → URL в массив.

### 4. Публичная страница: lightbox
`PortfolioDetailPage` — сетка миниатюр, клик открывает lightbox:
```bash
npm install yet-another-react-lightbox
```
